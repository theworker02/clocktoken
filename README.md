# clocktoken

Clock and reshape token text streams with deterministic transforms.

**Site:** https://theworker02.github.io/clocktoken/

## Install / run

```bash
git clone https://github.com/theworker02/clocktoken.git
cd clocktoken
node src/cli.js
node --test
```
